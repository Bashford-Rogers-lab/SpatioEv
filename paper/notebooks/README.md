# Development Notebooks

These notebooks are retained as analysis provenance for method development,
manuscript exploration, and dataset-specific workflows. The stable, user-facing
tutorial series lives in `tutorials/`.

For GitHub/package use:

- prefer `tutorials/` for reproducible examples;
- keep generated notebook outputs in `paper/notebooks/results/`, which is ignored by
  Git;
- move reusable logic into `spatioev/` modules before relying on it in a
  tutorial or manuscript script.
