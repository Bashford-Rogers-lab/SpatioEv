# Morphology and Topology Features

SpatioEv summarizes each epithelial niche as both a collection of cells and a
spatial graph. Morphology features capture cell shape, polarity, texture, and
nuclear/cytoplasmic structure. Topology features capture how cells are arranged
within the niche and how the niche interfaces with its surroundings.

These features support biological interpretation of ductal organization,
dysplasia, epithelial-stromal mixing, and invasive context.
