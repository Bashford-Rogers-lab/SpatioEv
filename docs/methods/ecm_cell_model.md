# ECM-Cell Model

SpatioEv models ECM-cell organization by linking segmented cells to collagen or
fiber objects, then summarizing distances, local fiber density, feature mapping,
spatial autocorrelation, and graph-derived ECM neighborhoods.

This module supports analyses where matrix architecture and cellular states are
jointly interpreted, such as invasive fronts, desmoplastic remodeling, or
collagen-poor micro-regions.
